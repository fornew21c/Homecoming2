## 이 환경의 함정

**사내망이 TLS 를 검사한다.**
- 시뮬레이터는 배포 서버(HTTPS)에 **못 붙는다** — `TLS 오류로 인해 보안 연결이 실패했습니다`.
  시뮬레이터 검증은 로컬 서버(`-homecomingBackend http://localhost:8811`)로 한다
- 파이썬 스크립트는 `Tools/hc_tls.py` 의 `context()` 를 쓴다. 안 쓰면
  `CERTIFICATE_VERIFY_FAILED`. `curl` 은 시스템 키체인을 써서 그냥 된다
- **실기기는 정상이다**

**폰과 맥이 다른 망에 있으면 로컬 서버에 못 닿는다.** 맥이 유선(`10.10.224.x`),
폰이 사내 Wi-Fi 면 라우팅이 안 된다. `.local` 도 IP 도 실패한다.

**`xcrun simctl launch` 가 간헐적으로 인자를 씹는다.** 실패하면 앱이
Info.plist 의 배포 URL 로 붙어 TLS 오류가 난다. 재시도 루프로 감싼다.

**공공데이터는 동시 요청을 조용히 실패시킨다.** 16개로 훑었을 때 결과를 믿을 수
없었다. 4개까지만.

## 오늘 한 일

**지도** — 가족·귀가자가 **같은 뷰**(`HomecomingJourneySection`)로 카드+지도를 본다.
폴리라인(도보 점선·탈것 실선), 경로 정류장 마커(수단 아이콘), 집 도착 반경 원,
지나온/남은 색 분리, 귀가자 마커 맥동, 카메라는 **남은 구간만** 담는다.

**버스 노선** — 999번 같은 경기 노선을 **실제 노선으로** 그린다.
`GET /bus/leg` 가 경유 정류장 좌표를 준다. 서울 시내버스는 자료에 없어 자동차 경로로 폴백.
API 규칙은 `BUS-API.md` 에 적어 뒀다.

**와이어 프로토콜 추가** (전부 추가만 — 옛 빌드가 안 깨진다)
`ContentState`: `lat`/`lon`/`homeLat`/`homeLon`/`homeRadius`.
`RouteLeg`: `busNo`. `/session/{id}/route`: `polyline`/`segments`/`stops`.

**서버가 앱이 보낸 집을 우선한다** — 경로에 박힌 집 사본은 저장 시점의 스냅샷이라,
집을 옮기면 4km 떨어진 옛 자리를 "집" 이라고 그렸다. 세션 시작 로그에
`집(위도, 경도) 출처=앱|경로` 를 남긴다.

**경로 없는 귀가** — 서버는 끝났다(`sessions.planned_seconds`, 검증 완료:
60분 적으면 도착예정이 그 값으로 고정되고 위치 보고로 흔들리지 않는다).
앱도 절반 됐다(ETA 출처 `.traveler`, 시작 가드 완화, 관측 보정에서 보호).
**남은 것은 앱의 입력 UI 하나** — `RouteCard` 의 `경로 없이` 항목에 붙인다.

**화면 구조** — 탭 4개(`귀가`·`경로`·`가족`·`설정`), 제목 상단, 전부 왼쪽 정렬.
실데이터/데모 세그먼트 제거(데모 코드는 검증용으로 남김), 안전귀가 모드 숨김
(`safetyCard` 를 `settingsTab` 에 되돌리면 부활한다).

**경로 만들기** — 지도에 검색 추가, 구간 N 의 지도가 **구간 N-1 지점**에서 열린다,
정류장이 더 빨리 뜬다(`.onEnd` → `.continuous` + 0.25초 디바운스).

**진행도를 한 벌로** — 카드의 노선도 점과 지도의 지나온/남은 색 분리가 **같은 값**을
쓴다. 서버가 `travelledMeters` 로 한 번 계산해 내려보낸다.

`remainingMeters` 로 되짚던 것을 버렸다 — 그 값은 이탈하면 집까지 직선거리로 **뜻이
바뀌어서** 노선도의 점을 앞으로 튀게 했다(60% 지점에서 1.5km 빠졌는데 점이 85% 로 전진).
지도에는 이탈 한 줄이 붙었다. 이탈하면 색 분리는 멈추고 귀가자 점만 선 밖으로 나가는데,
설명이 없으면 그 어긋남이 고장으로 읽힌다.

검증: `python3 Tools/verify-progress-sync.py` — 실제 경로 28.4km. 두 화면의 차이는
**끝에서 7.0m**(28.4km 의 0.025%)이고, 그것은 계산이 갈라진 것이 아니라 **자가 다른
것**이다 — 앱은 `CLLocation.distance`(측지선), 서버는 `haversine`(구). 옛 계산은 같은
자리에서 GPS 역행 7.8km, 이탈 4.2km 갈라졌다.

**처음에는 0m 로 잘못 쟀다.** 앱이 돌려준 "지나온 길이" 를 앱이 요청한 거리와
견줬는데 그 둘은 구조상 같다. 자른 자리를 서버 자로 되재야 값이 나온다.

서버 성질은 `Server/test_progress_sync.py` 가 지킨다.

**화면도 봤다** — 실기기에서 폰에 저장된 진짜 경로(25.9km)의 좌표열을 재생해, 잠금화면
카드가 갱신 50건 동안 25,950m → 324m 로 따라오고 노선도의 점과 지도의 색 경계가 함께
내려가는 것을 확인했다. 지하철 18.6km 구간에서도 경계가 계속 움직였다. 이탈 표시만
화면으로 안 봤다(숫자로는 확인).

그 과정에서 두 가지가 드러났다(설계문서 "화면 확인" 절에 적어 뒀다) —
세션 시작 푸시에 좌표가 없어 **가족 카드가 처음 뜰 때 지도가 없다**(첫 위치 보고 뒤에
뜬다), 그리고 **끝난 카드가 남아 있으면 갱신이 안 되는 것처럼 보인다**.

**경로 없이 귀가하기 — 앱까지 끝났다.** `SessionStartRequest.plannedMinutes` 로 적어
보내고(경로가 있으면 안 보낸다), `RouteCard` 의 `경로 없이` 아래에서 적고, 시작 가드가
`canStartWithoutRoute` 를 실제로 쓴다. 경로 목록이 비어도 그 줄을 그린다 — 회식·모임에서
귀가하는 사람이 정확히 그 경우다. 배포 서버에서 60분 → 도착예정 60.0분, 위치 보고 뒤에도
흔들림 0초를 확인했다.

**세션 시작 요청에 출발 좌표를 싣는다.** 가족 카드가 처음 뜰 때 지도가 없던 것을 없앤다
(자세한 것은 API 명세의 그 절). 서버·앱 양쪽을 고쳤다.

**`귀가` 탭에 이번 귀가 요약을 붙였다.** 경로는 `경로` 탭에서 고르는데 시작 버튼은
`귀가` 탭에 있어서, 무엇으로 시작하는지 보려면 탭을 옮겨 다녀야 했다. 대기 중일 때만
그린다 — 귀가 중에는 위의 카드가 같은 것을 더 자세히 말한다.

**경로를 기기 사이로 옮기는 도구.** `-homecomingDumpRoute <id|이름>` 이 소유 기기에서
경로를 서버가 받는 형태 그대로 찍고, `-homecomingImportRoute <base64>` 가 그것을 다른
기기 계정으로 저장한다. **계정은 기기를 넘지 않는다** — 키체인 항목이
`ThisDeviceOnly` 라 iCloud 로도 안 간다. 그래서 기기를 바꾸면 경로가 하나도 없었고,
손으로 다시 만드는 길밖에 없었다. 가족 권한으로 받는 좌표열(`/session/{id}/route`)에는
구간별 소요시간이 없어서 대신할 수 없다 — 그 값은 대중교통 앱 실측을 옮겨 적은 것이다
(실측 차이: 추정한 버스 11분·지하철 40분 vs 실제 16분·37분).

## 알아 둘 것

**지도의 자와 진행도의 자가 다를 수 있다.** 서버 `route_length()` 는 구간 **안**만
재고, 앱에 보내는 폴리라인은 구간 경계의 이음까지 이어 붙인다 — 이 경로에서 그
이음이 97.9m 다. 그래서 지도는 좌표열을 **구간별로** 누적해 자른다
(`App/Watching/RouteTrail.swift`). 이어붙인 `polyline` 으로 재면 진행도가 그만큼 밀린다.
`CLLocation.distance` 와 서버 `haversine()` 차이는 6.8m 로, 그건 문제가 아니었다.

**`POST /route` 는 같은 이름이면 덮어쓴다(id 를 유지한다).** 2026-08-20 에 이걸 모르고
"새로 저장한 뒤 옛 사본 삭제" 를 했다가 방금 올린 것을 두 번 지웠다. 이름이 같으면 저장이
곧 교체다 — 지울 것이 없다.

**`-homecomingHome <lat,lon>` 은 그 기기의 집 설정을 실제로 덮어쓴다.** 검증하려고
넘기면 사용자가 지정해 둔 집이 조용히 바뀐다. 2026-08-20 에 실기기에서 그렇게 했다.

**좌표열은 경로를 저장할 때 박힌다.** 그리기 로직을 고쳐도 이미 저장된 경로에는
반영되지 않는다 — **경로를 다시 저장해야** 한다. 오늘 세 번 이걸로 헤맸다
(도보 구간이 안 보임, 갈고리, 집이 두 개).

**MapKit 은 걸어갈 수 있는 자리까지만 그린다.** 아파트 단지 안쪽은 보행로 자료가
없어 100m 밖에서 끊긴다. `RouteTracer.ending(_:at:)` 이 도착점을 덧붙여 막는다.

**정류장 이름이 자료마다 다르다** — `아파트단지` ↔ `아파트단지`,
`환승로터리` ↔ `환승로터리`. 서버 `n_eq()` 가 점·쉼표·공백을 지우고 견준다.

**같은 이름의 정류장이 여럿이다** — `풍산역` 은 다섯 곳. 순환 노선의 방향은
직전 정류장에서 가까운 후보를 고르는 것으로 가린다.

  연결은 전부 끊었고 세션도 닫았다
